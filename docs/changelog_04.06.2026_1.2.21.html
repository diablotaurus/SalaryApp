🛡️ Распознавание источника по prod.marker

Файл prod.marker есть только в production и отсутствует в dev. Скрипт деплоя теперь проверяет наличие prod.marker рядом с собой (в корне источника): если он найден — значит скрипт запущен из production, и деплой останавливается.

# scripts/deploy_to_prod.py (блок проверок безопасности) if (source_path / "prod.marker").exists(): print_error( "Источник содержит prod.marker — похоже, скрипт запущен из PRODUCTION.\n" " Запускайте деплой из dev-репозитория (current). Остановлено." ) return 1

Зачем это нужно: начиная с v1.2.20 скрипт деплоя копируется и в production (prod\scripts\deploy_to_prod.py). Случайный запуск его из прода мог бы запустить деплой «прод в прод». Новая проверка это исключает.

Три взаимодополняющие проверки направления «dev → prod»

ПроверкаЧто предотвращает
Источник содержит prod.marker → отказ (новое)Запуск из production (при любой цели)
Цель должна содержать prod.markerДеплой «не туда» (цель — не настоящий прод)
Источник ≠ цельСовпадение путей
ОБНОВЛЁН scripts/deploy_to_prod.py — добавлена проверка prod.marker в источнике
ОБНОВЛЁН scripts/DEPLOY.md — описание проверок безопасности уточнено
