🤖 Непрерывная интеграция (CI)

Добавлен workflow .github/workflows/ci.yml, который при каждом push и pull_request запускает тесты.

  • Окружение: windows-latest (целевая ОС приложения; есть Tkinter для desktop-тестов).
  • Матрица версий Python: 3.11 и 3.12.
  • Зависимости из requirements-dev.txt (основные + pytest), кэш pip.
  • Запуск: python -m pytest -q (74 теста).
name: CI on: [push, pull_request] jobs: tests: runs-on: windows-latest strategy: matrix: python-version: ["3.11", "3.12"] steps: - uses: actions/checkout@v4 - uses: actions/setup-python@v5 with: { python-version: "${{ matrix.python-version }}", cache: pip } - run: pip install -r requirements-dev.txt - run: python -m pytest -q

Линтеры (black/flake8) в CI не подключались, чтобы не «краснить» сборку на неотформатированном коде. Существующий workflow encoding-check.yml не изменялся.
