Центрирование окон

🖼️ Управление размерами главного окна

Проблема: Главное окно при запуске разворачивалось на весь экран (state='zoomed'), но при восстановлении не имело контроля над минимальным размером, что могло привести к слишком маленькому окну.

❌ До изменений

  • Только полноэкранный режим: Окно всегда запускалось на весь экран
  • Нет минимального размера: При восстановлении окно могло быть слишком маленьким
  • "Магические числа": Размеры были жестко зашиты в код
  • Нет начального размера: Не задан размер окна при восстановлении из полноэкранного режима

✅ После изменений

  • Контролируемые размеры: Минимальный и начальный размеры заданы явно
  • Константы: Все размеры вынесены в отдельный файл констант
  • Гибкость: Легко изменить размеры без изменения кода
  • Логика MVC: Размеры окон вынесены в константы представления

Измененные файлы:

ОБНОВЛЕН desktop/app.py

Добавлено управление размерами главного окна:

# Настройка главного окна self.title(config.app.display_name_with_version) # Устанавливаем начальный размер окна self.geometry(f"{WINDOW_MAIN_DEFAULT_WIDTH}x{WINDOW_MAIN_DEFAULT_HEIGHT}") # Устанавливаем минимальный размер окна self.minsize(WINDOW_MAIN_MIN_WIDTH, WINDOW_MAIN_MIN_HEIGHT) # Разворачиваем на весь экран self.state('zoomed')
ДОБАВЛЕНЫ КОНСТАНТЫ desktop/views/constants.py

Добавлены константы для управления размерами окон:

# Константы для главного окна WINDOW_MAIN_MIN_WIDTH = 1024 WINDOW_MAIN_MIN_HEIGHT = 768 WINDOW_MAIN_DEFAULT_WIDTH = 1200 WINDOW_MAIN_DEFAULT_HEIGHT = 800
Результат: Главное окно теперь имеет контролируемые размеры. При запуске оно открывается в полноэкранном режиме, но при восстановлении имеет начальный размер 1200×800 пикселей и не может быть уменьшено меньше 1024×768 пикселей.

НОВЫЙ КЛАСС desktop/widgets/dialogs.py

Создан базовый класс BaseDialog с автоматическим центрированием:

class BaseDialog(tk.Toplevel): """Базовый класс для всех диалоговых окон""" def __init__(self, parent, title: str, **kwargs): super().__init__(parent) # Настройка окна self.title(title) # Сохраняем ссылку на родительское окно self.parent = parent # Делаем окно модальным self.transient(parent) self.grab_set() # Центрируем окно относительно родителя self._center_on_parent() def _center_on_parent(self): """Центрировать окно относительно родительского окна""" # Обновляем геометрию окна, чтобы получить актуальные размеры self.update_idletasks() # Получаем размеры родительского окна parent_x = self.parent.winfo_x() parent_y = self.parent.winfo_y() parent_width = self.parent.winfo_width() parent_height = self.parent.winfo_height() # Получаем размеры диалогового окна dialog_width = self.winfo_width() dialog_height = self.winfo_height() # Вычисляем позицию для центрирования x = parent_x + (parent_width - dialog_width) // 2 y = parent_y + (parent_height - dialog_height) // 2 # Устанавливаем позицию self.geometry(f"+{x}+{y}")

ДОБАВЛЕНЫ КОНСТАНТЫ desktop/views/constants.py

Добавлены константы для управления шириной полей ввода:

Константа Значение Назначение
SETTINGS_ENTRY_WIDTH 10 Ширина полей ввода (валюта, формат даты)
SETTINGS_SPINBOX_WIDTH 5 Ширина Spinbox (дни хранения резервных копий)
SETTINGS_COMBOBOX_WIDTH 10 Ширина Combobox (формат экспорта по умолчанию)

Пример использования констант в коде:

# Поле ввода валюты currency_entry = ttk.Entry( currency_frame, textvariable=self.settings_vars['currency'], width=SETTINGS_ENTRY_WIDTH # Используем константу ) # Spinbox для дней хранения retention_spin = ttk.Spinbox( retention_frame, textvariable=self.settings_vars['backup_days'], width=SETTINGS_SPINBOX_WIDTH # Используем константу )
Результат: Вкладка "Настройки" теперь полностью адаптивна и не имеет прокрутки. Все элементы отображаются на одном экране, поля ввода имеют компактную фиксированную ширину, а кнопки управления выровнены по центру. Улучшено использование доступного пространства.
