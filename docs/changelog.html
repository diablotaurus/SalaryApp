ChangeLog: SalaryApp - версия v.1.2.28

Краткий отчёт: надёжность данных, сворачивание лет на «Главной», вдвое более быстрый запуск и удобство эксплуатации

Версия: v.1.2.28

Дата: 15 октября 2026 г.

Предрелизные проверки: 208 тестов; попиксельное сравнение главной вкладки и сверка Excel-экспорта с прежней версией; замеры скорости на копии production-БД; критический Ruff; UTF-8 без BOM; точки входа.

Подробный отчёт: docs/changelog_15.10.2026_1.2.28.html

SalaryApp v.1.2.28 current

Кратко по проделанной работе

  • DATAОшибка ввода суммы больше не превращается молча в 0; срок хранения копий из настроек применяется ко всем копиям; стёртая в форме дата выплаты стирается из базы.
  • UIГоды на «Главной» сворачиваются (при запуске развёрнут текущий), в режиме «по кварталам» карточки раскладываются плиткой; полоса прокрутки видна только при необходимости, колёсико не сдвигает короткое содержимое.
  • SPEEDЭкспорт в Excel без pandas, тяжёлые библиотеки не загружаются при запуске desktop, бота и web.
  • OPSЛог web в файл, ошибки интерфейса desktop пишутся в журнал и показываются, деплой умеет перезапускать web и бота (--restart-services).

Скорость (копия production-БД, 4 года): запуск desktop 2.1–2.4 с → 0.8–0.9 с, перестройка после сохранения месяца ~0.6 с → ~0.27 с.

Совместимость: схема БД не менялась, миграций и новых зависимостей нет; pandas удалён из зависимостей. Развёрнутый год на «Главной» выглядит как раньше.
