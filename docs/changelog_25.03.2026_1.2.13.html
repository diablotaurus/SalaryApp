Telegram-бот: новый формат статистики

  • Раньше сообщение строилось как одна строковая таблица из шести колонок: месяц, аванс, дата аванса, зарплата, дата зарплаты, итог.
  • На мобильном экране Telegram таблица переносилась на несколько строк и визуально разъезжалась.
  • Теперь каждая запись месяца показывается отдельным блоком:
Статистика за 2026 год Январь Аванс: 20 783.87 • 28.01.2026 Зарплата: 84 562.16 • 13.02.2026 Итого: 105 346.03 Февраль Аванс: 41 021.06 • 27.02.2026 Зарплата: 68 673.96 • 13.03.2026 Итого: 109 695.02 Итого за год: 215 041.05
Такой формат не требует горизонтальной прокрутки, не зависит от ширины моноширинного блока и остается читаемым в обычном Telegram-сообщении.

Команды по выбранному году

  • Добавлен обработчик команд формата /YYYY через фильтр регулярного выражения.
  • Команды /2025 и /2024 работают без отдельного дублирования кода, потому что используют общий метод форматирования по году.
  • Команда /current теперь является частным случаем общего форматтера: передается текущий год из datetime.now().year.
  • Справка бота обновлена и содержит пример команды /2025.

Исправление запуска из run_bot.bat

  • Проблема с кракозябрами была вызвана тем, что cmd.exe некорректно читает кириллицу в .bat, сохраненном в UTF-8 без BOM.
  • Отдельно в конкретном окружении команда chcp не находилась через PATH.
  • Решение: убрать кириллицу из текста batch-файла и заменить вызов chcp на безопасную форму %SystemRoot%\System32\chcp.com с проверкой существования.
  • Результат: при запуске run_bot.bat консольный вывод остается читаемым и не начинается с ошибки про chcp.
