🖥️ Исправление режима отображения окна

Проблема: Приложение открывалось в полноэкранном режиме вместо развернутого на весь экран, что мешало доступу к другим элементам интерфейса ОС.
ДО изменений:
# Окно открывалось в полноэкранном режиме self.geometry("1920x1200") self.attributes('-fullscreen', True)

Проблемы: Полноэкранный режим скрывал панель задач Windows, не было возможности свернуть/развернуть окно стандартным способом.

ПОСЛЕ изменений:
# Окно открывается развернутым на весь экран self.state('zoomed') # Для Windows

Решение: Использование метода state('zoomed') для открытия окна в развернутом состоянии с сохранением стандартных элементов управления окном.

ИСПРАВЛЕНО desktop/app.py

Изменена строка 30: self.geometry("1920x1200") → self.state('zoomed')

Преимущества решения:

  • Стандартное поведение Windows: Окно открывается развернутым, но не в полноэкранном режиме
  • Сохранение элементов управления: Остаются кнопки свернуть/развернуть/закрыть
  • Доступ к панели задач: Пользователь может легко переключаться между приложениями
  • Кроссплатформенность: Метод state('zoomed') работает корректно в Windows

📊 Исправление ошибок визуализации данных

Критическая ошибка: При переходе на вкладку "Аналитика" возникала ошибка: 'rgba(255, 140, 66, 0.2)' is not a valid color value

❌ Проблема

Tkinter и matplotlib не поддерживают цвета в формате RGBA со строковым представлением. Формат 'rgba(255, 140, 66, 0.2)' является CSS-форматом и не распознается библиотеками визуализации Python.

Не удалось обновить аналитику: 'rgba(255, 140, 66, 0.2)' is not a valid color value

✅ Решение

Все цвета RGBA были заменены на hex-формат #RRGGBB, который поддерживается и tkinter, и matplotlib. Цветовая схема графиков сохранена.

#FF8C42
#FF6384
#36A2EB
#4BC0C0

Изменения в коде:

ИСПРАВЛЕНО desktop/views/report_view.py

Исправлены методы update_growth_chart() и update_average_chart():

# Было (строка 218): fill_color = dataset.get('backgroundColor', 'rgba(255, 140, 66, 0.2)') # Стало (строка 218): fill_color = dataset.get('backgroundColor', '#FF8C42') # Было (строка 290): default_fill_colors = ['rgba(255, 99, 132, 0.2)', 'rgba(54, 162, 235, 0.2)', 'rgba(75, 192, 192, 0.2)'] # Стало (строка 290): default_fill_colors = ['#FF6384', '#36A2EB', '#4BC0C0']
ИСПРАВЛЕНО core/services/statistics_service.py

Исправлены методы генерации данных для графиков:

# Было (строка 67): 'backgroundColor': 'rgba(255, 140, 66, 0.2)' # Стало (строка 67): 'backgroundColor': '#FF8C42' # Аналогично исправлены строки 114, 119, 124
Результат: Графики на вкладке "Аналитика" теперь отображаются корректно без ошибок. Все цвета преобразованы в совместимый формат, сохраняя визуальную привлекательность и читаемость данных.

📏 Оптимизация размеров графиков

Проблема: На графике "Помесячные данные" подписи оси X (названия месяцев) не помещались в область отображения, перекрываясь с другими элементами интерфейса.

Решение: уменьшение высоты графика и настройка отступов

УЛУЧШЕНО desktop/views/report_view.py

Изменен метод _create_monthly_chart():

# Было (строка 75): fig = Figure(figsize=(8, 5), dpi=100) # Стало (строка 75): fig = Figure(figsize=(8, 4.7), dpi=100) # Уменьшена высота # Добавлена настройка отступов (строка 83): fig.subplots_adjust(bottom=0.15) # Увеличен отступ снизу

Дополнительно изменен метод update_monthly_chart() для улучшения читаемости подписей:

# Было (строка 188): ax.set_xticklabels(labels, rotation=45) # Стало (строка 188): ax.set_xticklabels(labels, rotation=0) # Горизонтальные подписи

Архитектурное улучшение:

Также изменен способ упаковки графика для предотвращения растягивания:

# Изменена упаковка холста для сохранения пропорций canvas.get_tk_widget().grid(row=0, column=0, sticky="nsew") frame.grid_rowconfigure(0, weight=1) frame.grid_columnconfigure(0, weight=1)
Результат: График "Помесячные данные" теперь отображается корректно, все подписи оси X полностью видны, легенда месяцев не обрезается. Визуальное восприятие данных значительно улучшено.
