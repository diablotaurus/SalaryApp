2. Бот с меню

[ ➕ Внести ]   [ 📅 Этот год ]
[ 📆 По годам ] [ 📊 Отчёты  ]
[ ❓ Помощь ]
  • ADDEDПостоянное меню под полем ввода. Появляется по /start и возвращается после сохранения или отмены ввода. Кнопки работают и посреди ввода: «Этот год» покажет сводку, не сбросив начатое.
  • ADDEDКнопка «Меню» Telegram со списком команд (set_my_commands): /add, /current, /years, /reports, /records, /cancel, /help.
  • CHANGED«📅 Этот год», /current и /2025 показывают короткую сводку вместо 12 блоков: итог, среднемесячное и его изменение к прошлому году, «год к году» за тот же период, последние три месяца. Кнопки ◀ ▶ листают годы с данными, «Подробно» — по месяцам с датами, «📈 График» — график года. Листание меняет то же сообщение.
  • ADDED«📆 По годам» (/years): итог каждого года, число месяцев, среднемесячное и рост к прошлому году, итог за всё время; кнопки годов открывают их сводки. Годы сравниваются по среднемесячному — честно и для неполного года.
  • ADDEDПосле сохранения месяца — сравнение со средним за последние 12 месяцев: «📈 На 5 % выше среднего (110 000,00)». Только для месяца с выплаченной зарплатой и при истории не меньше трёх выплаченных месяцев.
  • Обновлена справка: кнопки, команды, формат сумм и дат, уведомления.

3. Отчёты

  • ADDED«📊 Отчёты» (/reports): график года, динамика по годам, рекорды, Excel-файл.
  • ADDEDГрафики картинкой: помесячно выбранный год рядом с прошлым; среднемесячный доход по годам с подписями. matplotlib загружается только при рисовании (запуск бота не замедляется), рисование — через Figure и Agg без GUI, в отдельном потоке, чтобы бот не замирал.
  • ADDEDГод к году: «Январь–сентябрь: +6,2 % к тому же периоду 2025». Период — до последнего месяца с выплаченной зарплатой, чтобы месяц, где пока только аванс, не занижал сравнение.
  • ADDEDРекорды (/records): три лучших месяца, лучший полный год по сумме (неполный текущий год не проигрывает заведомо), год с самым высоким среднемесячным.
  • ADDEDExcel-файл со всеми данными прямо в чат. Копия на диске сразу удаляется, как в web-экспорте.
  • ADDEDГодовой итог с графиком приходит сам — в январе, вечером по МСК, как только внесена зарплата за декабрь (она приходит в середине января), и не позже 25 января. Один раз за год. Не 1 января сознательно: иначе итог был бы без декабрьской зарплаты.
  • CHANGEDВыключатель в desktop теперь называется «Уведомления в Telegram: напоминания о выплатах и итоги года» и управляет обоими уведомлениями.

5. Устройство

  • REFACTOREDОтчёты — отдельный роутер bot/handlers/reports.py, подключается раньше роутера ввода. Тексты — bot/presenters/year_report.py, графики — bot/presenters/charts.py, кнопки — bot/keyboards/menu.py.
  • Расчёты — в ядре: StatisticsService.compare_with_recent_average, compare_year_to_date, get_records, percent_change; когда отправлять годовой итог — core/services/annual_report_service.py. Бот получает данные через API-фасад, как и раньше.
  • Год последнего годового итога хранится служебным ключом reports.annual_sent в таблице settings, без миграции.

8. Обновление production

  1. Убедиться, что версии библиотек совпадают с requirements.txt (деплой сам предупредит о расхождении).
  2. Закрыть desktop-приложение production и запустить деплой с перезапуском сервисов.
  3. Отправить боту /start — появится обновлённое меню с «📊 Отчёты».
python scripts/deploy_to_prod.py --restart-services

Совместимость: схема БД не менялась, миграций нет. Служебный ключ reports.annual_sent прежние версии игнорируют. Возврат к 1.2.31 возможен обычным деплоем предыдущего кода; версии библиотек при этом можно оставить новыми — код 1.2.31 проверен на них в CI.
