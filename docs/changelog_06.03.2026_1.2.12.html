ChangeLog: SalaryApp - версия v.1.2.12

Донастройка среднемесячного расчета по реальному графику выплат: учет наступления salary_date

Версия: v.1.2.12

Дата: 06 марта 2026 г.

Область изменений: core/services/statistics_service.py, tests/unit/core/services/test_statistics_service_average.py, version.txt

Причина изменений: среднемесячное на реальных данных оставалось некорректным до учета фактической даты выплаты зарплаты за месяц

Статус: ✅ Выполнено и проверено

SalaryApp v.1.2.12 current

Суть исправления

  • FIXEDМесяц теперь учитывается в среднем только после фактической выплаты зарплаты за этот месяц.
  • CHANGEDПравило расчета основано на salary_date, а не только на суммах.
  • ADDEDДобавлены дополнительные тесты для сценариев до/после наступления даты зарплаты и для legacy-данных без даты.

Новая бизнес-логика среднемесячного

  • Запись учитывается только если salary > 0.
  • Если salary_date задана: запись учитывается только при salary_date <= now.
  • Если salary_date не задана (legacy): учитываются только месяцы строго раньше текущего.
  • Текущий месяц с одним авансом не может попасть в среднемесячное до выплаты зарплаты.
