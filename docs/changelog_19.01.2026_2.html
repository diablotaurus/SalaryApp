📚 Реализация системы управления версиями

Цель: Создать простую и эффективную систему управления версиями приложения, где версия хранится в отдельном файле и автоматически подхватывается при запуске.

ДО изменений:
# Версия была захардкожена @dataclass class AppConfig: version: str = "1.0.0" # Заголовок окна без версии self.title("Учет заработной платы")

Проблемы: Версия захардкожена, нет единого источника, сложно обновлять

ПОСЛЕ изменений:
# Файл version.txt 0.0.3 # settings.py автоматически читает версию def _read_version_from_file(self): version_file = root_dir / "version.txt" with open(version_file, 'r') as f: self.version = f.read().strip() # Заголовок с версией self.title(config.app.display_name_with_version)

Преимущества: Легкое управление версиями, автоматическое обновление, CI/CD готовность

Ключевые изменения в системе версионирования:

НОВЫЙ ФАЙЛ version.txt

Создан в корневой директории проекта. Содержит текущую версию приложения в формате semver (Semantic Versioning).

НОВЫЙ ФАЙЛ salary_icon.ico

Иконка приложения, добавленная в корневую директорию. Используется как иконка главного окна.

Результат: Теперь для обновления версии приложения достаточно изменить одну строку в файле version.txt. При следующем запуске приложение автоматически подхватит новую версию и отобразит её в заголовке окна.

# Добавлены новые поля в AppConfig @dataclass class AppConfig: app_name: str = "Salary Tracker" display_name: str = "Учет заработной платы" version: str = "1.0.0" @property def display_name_with_version(self) -> str: """Возвращает название приложения с версией""" return f"{self.display_name} v{self.version}"

Преимущества централизации:

  • Единый источник истины: Все текстовые константы в одном месте
  • Устранение дублирования: Нет повторяющихся строк в коде
  • Легкость изменений: Изменение в одном месте применяется везде
  • Подготовка к локализации: Простая замена текстов на другие языки
  • Улучшенная читаемость: Код становится чище и понятнее
  • Автоматизация версионирования: Легко интегрировать с CI/CD

🎨 Добавление иконки приложения

salary_icon.ico - иконка приложения

Устанавливается как иконка главного окна для улучшения визуальной идентификации

Реализация в коде:

# В методе __init__ класса App try: icon_path = os.path.join(os.path.dirname(os.path.dirname(__file__)), "salary_icon.ico") if os.path.exists(icon_path): self.iconbitmap(icon_path) except: pass # Иконка не критична для работы приложения

Особенности реализации:

  • Отказоустойчивость: Код завернут в try-except, чтобы отсутствие иконки не ломало приложение
  • Динамический путь: Иконка ищется относительно расположения файла app.py
  • Проверка существования: Проверяется, существует ли файл иконки перед установкой
  • Кроссплатформенность: Используется os.path для корректной работы на разных ОС
Визуальный результат: Приложение теперь имеет собственную иконку в заголовке окна и на панели задач, что улучшает профессиональный вид и упрощает идентификацию среди других открытых окон.
