🧹 Удаление SalaryController

Контекст: Класс SalaryController существовал с самого первого коммита как тонкий контроллер-обёртка для операций с зарплатой (открыть диалог / сохранить / получить). Однако в реальном приложении он никогда не инстанцировался — только в собственном тесте. Его обязанности фактически выполняет связка SalaryDialog → NavigationController → MainTabController.

Почему удалён

  • Мёртвый код: по всей истории git SalaryController(...) не вызывался нигде, кроме теста.
  • Нарушение DRY: класс дублировал часть API фасада NavigationController, создавая «два способа сделать одно и то же».
  • Источник путаницы: наличие неподключённого контроллера усложняло понимание архитектуры.

Реальная (рабочая) схема — не изменилась

SalaryDialog
→
NavigationController
→
MainTabController
→
SalaryAPI
УДАЛЕНО desktop/controllers/salary_controller.py
УДАЛЕНО tests/unit/desktop/controllers/test_salary_controller.py
ОБНОВЛЕНО desktop/controllers/__init__.py
# было from .navigation_controller import NavigationController from .salary_controller import SalaryController # стало from .navigation_controller import NavigationController
Результат: Удалён осиротевший дублёр. Кодовая база чище, остался единственный путь выполнения операций с зарплатой. Рабочая функциональность desktop-приложения полностью сохранена.
