2. Надёжность данных

Ввод сумм

  • FIXEDMoneyUtils.parse_amount при любой ошибке возвращал 0.0, и диалог ввода сохранял ноль поверх настоящей суммы месяца без предупреждения. Теперь неоднозначный или некорректный ввод даёт сообщение с названием поля, например «аванс «87432,7l» — ожидается число, например 87 432,71», и ничего не сохраняется.
  • Понимаются пробелы любого вида, включая неразрывные (так вставляются суммы из банковских приложений), и форматы 12,345.67 / 12.345,67: десятичный разделитель — правый.
  • Отклоняются опечатки, 87.432.71, больше двух знаков после разделителя (12,345, вероятно, тысячи), nan, 1e3. Пустое поле по-прежнему означает 0.
  • Web-форма отдельного исправления не потребовала: поля сумм имеют type="number" required min="0" step="0.01", и браузер сам не отправляет некорректные значения (проверено на dev-сервере).

Срок хранения резервных копий

  • FIXEDСервис бэкапов сам читает настройку backup_days и применяет её ко всем копиям: ручным, из web, при закрытии и автоматическим перед восстановлением. Раньше при сроке, например, 90 дней любая ручная копия удаляла всё старше 30.
  • Убрана временная подмена глобального конфига в контроллере desktop. Если настройку прочитать нельзя, используется значение из конфигурации.

Очистка дат выплат

  • CHANGEDФормы desktop и web подставляют сохранённые даты в поля, поэтому пустое поле означает, что пользователь стёр дату, и теперь она стирается из базы. None (бот при ответе «-», API-запрос без поля даты) оставляет прежнюю дату.
  • Прежнее поведение «пустая дата не затирает сохранённую» было закреплено тестом; решение изменить его согласовано с пользователем, тест заменён тремя новыми.

3. Вкладка «Главная»

Сворачивание лет

  • ADDEDКлик по стрелке ▶/▼ или году сворачивает и разворачивает карточку. Свёрнутый год показывает заголовок, кнопки «Редактировать»/«Удалить год» и строку итогов.
  • Сетка месяцев строится при первом разворачивании, затем только скрывается: повторное разворачивание мгновенное.
  • При запуске развёрнут текущий год, а если за него ещё нет данных, — последний год с данными. Выбор пользователя сохраняется до закрытия приложения; впервые появившийся текущий год разворачивается сам.
  • Развёрнутый год выглядит как раньше (сравнение скриншотов до пикселя).

Раскладка плиткой (режим «по кварталам»)

  • ADDEDКаждая следующая карточка встаёт в более короткую колонку: свёрнутые годы выстраиваются по порядку рядом с развёрнутым, без пустот. Идея пользователя.
  • Карточка, по которой кликнули, не меняет колонку; порядок лет сверху вниз сохраняется. Стандартный режим не изменился.

Полоса прокрутки и колёсико

  • ADDEDПолоса прокрутки видна только тогда, когда карточки не помещаются (виджет AutoHideScrollbar). При видимой полосе вид совпадает с прежним до пикселя.
  • FIXEDЕсли содержимое короче окна, Tk разрешал двигать его внутри окна, и колёсико вверх сдвигало карточки вниз, оставляя пустоту сверху. Ошибка была и раньше и стала заметна со свёрнутыми годами. Область прокрутки теперь не меньше видимой высоты.
  • Стрелки рисуются шрифтом Segoe UI Symbol (в обычном шрифте ▶ мельче ▼); фон области прокрутки совпадает с панелью.

4. Скорость

Замеры на копии production-БД (4 года данных), одним и тем же скриптом. Копия создавалась через SQLite Backup API в режиме только чтения и удалялась после замеров.

Действие1.2.271.2.28
Запуск desktop до готового окна2.1–2.4 с0.8–0.9 с
Переход на «Главную»~0.18 с~0.11 с
Перестройка после сохранения месяца~0.6 с~0.27 с
Экспорт в Excel по кнопке~0.55 с~0.6 с
  • CHANGEDЭкспорт в Excel пишется напрямую через openpyxl; pandas удалён из зависимостей, run_web.bat и README. Цепочка «контроллер → API → экспорт» загружала pandas при каждом запуске desktop, бота и web.
  • openpyxl сам загружается около 0.7 с, поэтому импортируется только в момент экспорта, а не при запуске.
  • Файл сверен с прежним ячейка в ячейку: те же листы, значения, типы и оформление заголовков. «Итого» округлено до копеек (раньше шум float раздувал ширину колонки).
  • Проверка зависимостей web при старте использует importlib.util.find_spec и больше не загружает openpyxl и matplotlib только ради проверки наличия.
  • Свёрнутые годы ускоряют запуск и перестройку: время запуска почти не растёт с длиной истории.

Production: pandas можно не удалять из установленного Python — он больше не загружается. Новых зависимостей нет.

5. Эксплуатация

  • FIXEDWeb пишет лог в logs/web.log с ротацией (5 МБ × 3). В production web запускается через pythonw без консоли, и раньше его логи и ошибки терялись. Проверено запуском dev-сервера через pythonw.
  • Настройка логирования web и бота вынесена в общий помощник core/utils/logging_setup.py; у бота поведение прежнее.
  • FIXEDНеобработанная ошибка в обработчике интерфейса desktop (кнопка, диалог) записывается в журнал с трассировкой и показывается пользователю с путём к журналу. Раньше Tk печатал её в отсутствующую консоль.
  • ADDEDДеплой: флаг --restart-services перезапускает задачи Планировщика SalaryAppWeb и SalaryAppBot и проверяет состояние Running. Скрипт дожидается фактической остановки (при политике IgnoreNew запуск поверх работающего экземпляра игнорируется), пропускает отсутствующие и отключённые задачи. При сбое — код 1 без отката кода. Без флага — напоминание о сервисах, работающих на старом коде. DEPLOY.md дополнен.
  • Если web не хватает зависимостей, ожидание нажатия клавиши выполняется только при наличии консоли (под pythonw input() падал сам).

6. Найдено и исправлено попутно

  • FIXEDЭкспорт в Excel на пустой базе падал: суммы NULL складывались как None + None. Теперь создаётся файл с заголовками и нулями.
  • FIXEDТесты с окном Tk иногда пропускались: повторное создание Tk() на Windows нестабильно. Теперь одно окно на весь прогон (tests/unit/desktop/conftest.py).
  • Определение текущего периода в контроллере главной вкладки вынесено в общий метод (было продублировано).

9. Обновление production

  1. Закрыть desktop-приложение production.
  2. Запустить деплой с перезапуском сервисов: web и бот изменились (логирование), и без перезапуска продолжили бы работать на старом коде.
  3. Проверить заголовок окна desktop (1.2.28), появление logs/web.log и подключение бота в logs/bot.log.
python scripts/deploy_to_prod.py --restart-services
