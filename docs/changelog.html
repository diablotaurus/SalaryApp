Кратко по проделанной работе

  • SECURITYTelegram-бот допускает только пользователей из BOT_ALLOWED_IDS. Внешние запросы ко всем Web API требуют X-API-Key; ключ в URL не принимается.
  • DATAМиграция 005_salary_integrity: хранение денег в целых копейках, уникальный год/месяц, ограничения и атомарный UPSERT. Перед изменением непустой БД создаётся резервная копия.
  • BACKUPСогласованный SQLite-снимок, проверка архива и БД, ограничение путей, автоматический бэкап перед восстановлением.
  • DEPLOYНеполный бэкап останавливает обновление, включая --yes. Ошибки очистки, копирования и итоговой проверки запускают откат кода.
  • MVCДобавлены SettingsService и AnalyticsRepository, настройки передаются во View контроллером, команды бота вынесены из bootstrap.
  • WEBОбычный запуск через Waitress, рабочие восстановление и удаление резервных копий, JSON-ошибки API и логирование.
  • QUALITYАбсолютные runtime-пути, UTF-8 для BAT-файлов, обновлённые зависимости, Python 3.13 в CI, Ruff и pip-audit.

Перед обновлением: остановите desktop, Web и бота; обновите зависимости. Имеющийся production-файл bot/.env сохраняется скриптом деплоя. Production в рамках подготовки этого релиза не обновлялся.

Важно: после миграции 005 нельзя запускать старый код на новой БД. Для возврата к прежней версии потребуется согласованное восстановление кода и домиграционной БД. Подробности и ограничения приведены в инструкции по обновлению.
