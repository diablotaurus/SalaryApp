ChangeLog: SalaryApp - версия v.1.2.26

Краткий отчёт: устранение зависимости unit-теста от рабочей БД и проверка в чистой копии проекта

Версия: v.1.2.26

Дата: 27 августа 2026 г.

Предрелизные проверки: 110 тестов в чистой копии исходников; запрет обращения исправленного теста к SQLite; критический Ruff; UTF-8 без BOM; пять точек входа.

Подробный отчёт: docs/changelog_27.08.2026_1.2.26.html

SalaryApp v.1.2.26 current

Кратко по проделанной работе

  • TESTВ test_main_tab_controller_refresh_history добавлена подмена SettingsAPI.get_settings. Unit-тест больше не зависит от таблицы settings в локальной БД.
  • CHECKИсправление проверено отдельно с запретом подключения к SQLite; полный набор из 110 тестов выполнен в чистой временной копии исходников без dev-БД и bot/.env.
  • SCOPEКод приложения, миграции, зависимости и workflow не менялись. Новые функции и классы не добавлены; тесты не отключались.

Причина отдельного релиза: после публикации 1.2.25 GitHub Actions выявил один неизолированный тест: 109 успешных и один сбой на Python 3.11, 3.12 и 3.13. Локальная таблица настроек скрывала проблему. Подробности исправления и ссылка на исходный CI приведены в новом отчёте.

Изменения приложения из 1.2.25: безопасность Telegram и Web, деньги в копейках, резервные копии, rollback деплоя, разделение слоёв и обновлённые зависимости сохранены. Полный перечень находится в предыдущем отчёте.

Публикация: результат удалённого запуска проверяется после push в GitHub Actions. Production при подготовке релиза не обновлялся.

Важно: после миграции 005 нельзя запускать старый код на новой БД. Для возврата к прежней версии потребуется согласованное восстановление кода и домиграционной БД. Подробности и ограничения приведены в инструкции по обновлению.
