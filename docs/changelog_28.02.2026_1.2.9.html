ChangeLog: настройка шрифта данных в карточках месяцев

Реализовано управление размером шрифта для табличной части помесячной разбивки на вкладке «Главная»

Версия: v.1.2.9

Дата: 28 февраля 2026 г.

Область изменений: Desktop UI (вкладки «Настройки» и «Главная»)

Статус: выполнено и проверено

SalaryApp v.1.2.9 current

Что изменено

  • ADDEDВ блок «Размер шрифта» добавлена новая настройка: Данные в карточке месяца.
  • CHANGEDНа вкладке «Главная» в карточках месяцев размер шрифта для табличного блока выплат теперь берется из новой настройки.
  • IMPROVEDВысота зоны выплат в карточке месяца стала рассчитываться с учетом выбранного размера шрифта, чтобы не ломалась компоновка.

Какие элементы теперь управляются новой настройкой

  • Заголовки колонок: Дата, Сумма.
  • Подписи строк: Аванс, Зарплата.
  • Текст данных: даты выплат и значения сумм.

Измененные файлы

desktop/views/constants/texts.py
  • Добавлена текстовая константа TEXT_MONTH_DATA_FONT_SIZE.
  • Добавлено значение по умолчанию DEFAULT_MONTH_DATA_FONT_SIZE = 8.
desktop/views/settings/settings_view.py
  • Добавлена новая строка в блоке «Размер шрифта» со spinbox для month_data_font_size.
  • Ключ month_data_font_size добавлен в сброс к значениям по умолчанию.
desktop/views/main/main_view.py
  • Добавлено чтение настройки month_data_font_size при отрисовке истории.
  • Все шрифты табличной части выплат переведены с фиксированного размера 8 на значение из настройки.
  • Высота блока выплат изменена на расчетную: max(58, 6 * size + 10).

Совместимость и безопасность изменений

  • SAFEПроверены точки запуска и вызовы: `StartSalary.pyw`, `run_web.py`, `run_bot.py`, `desktop/app.py`, `bot/main.py`.
