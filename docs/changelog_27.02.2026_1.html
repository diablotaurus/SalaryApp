🧩 ChangeLog: Desktop UI доработки Главной и Настроек — v.1.2.7

Переработка карточек месяцев, новые настройки отображения и оптимизация компоновки вкладки «Настройки»

Версия: v.1.2.7

Дата: 27 февраля 2026 г.

Область изменений: desktop/views/main/main_view.py, desktop/views/settings/settings_view.py, desktop/views/constants/texts.py, docs/

Тип изменений: UI/UX улучшения, расширение настроек, исправления компоновки

Статус: ✅ Выполнено и проверено

Ключевые изменения

  • CHANGE Изменен формат отображения месячной карточки на вкладке «Главная»: данные выплат представлены в структуре Дата - Сумма для аванса и зарплаты.
  • NEW Добавлены настройки размеров шрифта для карточек месяцев: month_title_font_size и month_total_font_size.
  • NEW Добавлена отдельная настройка вида блока статистики на Главной: main_stats_layout_mode = row|column.
  • CHANGE Логика блока статистики в карточке года отвязана от вида истории (6х2/3х4), теперь управляется отдельной настройкой.
  • IMPROVE Вкладка «Настройки» переразложена по логическим секциям: «Общие настройки», «Вкладка Главная», «Вкладка Аналитика», «Резервное копирование», «Настройки экспорта».
  • FIX Исправлены визуальные регрессии после уплотнения layout: корректное положение кнопок «Сохранить/Сбросить», равная ширина блоков, корректная группировка всех цветов в одном блоке.
  • CHANGE Обновлен формат даты по умолчанию: DEFAULT_DATE_FORMAT = "%d.%m.%Y".

Детализация по файлам

1) Main UI (Главная)

desktop/views/main/main_view.py
  • Обновлен рендер месячной ячейки: вместо вертикального списка «Аванс/Дата/Зарплата/Дата» используется табличный блок «Дата - Сумма».
  • Добавлено чтение и применение на лету настроек размера шрифтов месяца и строки «Итого».
  • Добавлен безопасный парсинг размеров шрифта с ограничением диапазона (защита от некорректных значений).
  • Добавлен отдельный режим отображения блока статистики карточки года (row/column).

2) Settings UI (Настройки)

desktop/views/settings/settings_view.py
  • Добавлены новые элементы управления: Вид блока статистики, размеры шрифтов месяца/итого.
  • Добавлены новые логические блоки интерфейса, соответствующие согласованному макету.
  • Оптимизирована компоновка для меньшей вертикальной высоты: часть настроек перенесена в двухколоночные ряды.
  • Восстановлена исходная компоновка панели действий (кнопки «Сохранить» и «Сбросить» в ожидаемом порядке и расположении).
  • Обновлен reset с учетом всех новых параметров.

3) Константы и default-значения

desktop/views/constants/texts.py
  • Добавлены константы для новых подписей и режимов настройки UI.
  • Добавлены default-значения для новых параметров: DEFAULT_MAIN_STATS_LAYOUT_MODE, DEFAULT_MONTH_TITLE_FONT_SIZE, DEFAULT_MONTH_TOTAL_FONT_SIZE.
  • Обновлено default-значение формата даты на %d.%m.%Y.

Архитектурные и UX-результаты

  • Соблюдено разделение ответственности: представления управляют только UI, настройки хранятся через существующий Settings API/Repository.
  • Изменения внедрены без удаления функций и модулей, только через расширение существующих компонентов.
  • Повышена управляемость интерфейса: ключевые аспекты вида Главной вкладки вынесены в пользовательские настройки.
  • Улучшена читаемость месячных карточек при сохранении текущих бизнес-правил (скрытие нулевых выплат, сохранение формата даты из данных).
Итог: Desktop-часть стала более гибкой в настройке, визуально стабильной и удобной при работе в неразвернутом окне.

Проверка и совместимость

  • Проверен синтаксис измененных Python-файлов через python -m py_compile — ошибок нет.
  • Проверены точки входа проекта: StartSalary.pyw, run_web.py, run_bot.py, desktop/app.py, bot/main.py — несовместимостей не внесено.
  • Изменения обратно совместимы на уровне структуры данных и основных сценариев запуска.
