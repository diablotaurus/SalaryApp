📚 Создание централизованного файла констант

Цель: Устранить разбросанные строковые литералы по всем view-файлам, улучшить поддерживаемость и подготовить почву для возможной локализации приложения.
ДО изменений:
# В каждом view-файле были разбросаны строковые литералы button = ttk.Button( text="Добавить данные", command=self.controller.add_data ) label = ttk.Label( text="История заработной платы" ) # Проблемы: дублирование, опечатки, сложность изменения

Проблемы: Дублирование кода, риск опечаток, сложность внесения изменений, невозможность локализации

ПОСЛЕ изменений:
# desktop/views/constants.py TEXT_ADD_DATA = "Добавить данные" TEXT_HISTORY_TITLE = "История заработной платы" # В view-файлах button = ttk.Button( text=TEXT_ADD_DATA, command=self.controller.add_data ) label = ttk.Label( text=TEXT_HISTORY_TITLE )

Преимущества: Централизация, единообразие, легкость изменений, подготовка к локализации

Структура файла constants.py:

# Основные разделы файла: 1. Общие тексты для кнопок и действий 2. Тексты для главного окна 3. Тексты для диалога зарплаты 4. Тексты для вкладки отчетов 5. Тексты для вкладки настроек 6. Тексты для диалога экспорта 7. Тексты подтверждений 8. Значения по умолчанию 9. Размеры и отступы 10. Размеры окон 11. Параметры текста 12. Диалоговые окна

  • TEXT_ADD_DATA = "Добавить данные"

  • DIALOG_SALARY_TITLE = "Ввод данных по зарплаты"

📤 Улучшение диалога экспорта истории

ДО улучшений:
# Размер окна self.geometry("400x300") # Отображение информации info_label = ttk.Label( info_frame, text="Очень длинный текст который не помещается...", justify=tk.LEFT )

Проблемы: Маленькое окно, текст не помещается, плохой UX

ПОСЛЕ улучшений:
# Размер окна из констант self.geometry(WINDOW_EXPORT_DIALOG_SIZE) # "430x470" # Улучшенное отображение информации info_label = ttk.Label( info_frame, text=TEXT_EXPORT_DETAILS, justify=tk.LEFT, wraplength=TEXT_WRAPLENGTH_EXPORT_INFO, # 380 font=('Segoe UI', 9) )

Улучшения: Увеличенное окно, перенос текста, лучшая читаемость

Внесенные улучшения в диалог экспорта:

  • Увеличен размер окна: с 400x300 до 430x470 пикселей
  • Добавлен параметр wraplength: автоматический перенос текста по словам
  • Улучшен текст информации: более подробное и структурированное описание
  • Вынос размеров в константы: легкое изменение размеров в будущем
  • Улучшены отступы: более сбалансированное расположение элементов
Результат: Диалоговое окно экспорта теперь удобнее для пользователей. Весь текст информации отображается полностью, без обрезания. Интерфейс стал более профессиональным и удобным.

Полная обратная совместимость: Все изменения не затрагивают бизнес-логику приложения, API контроллеров или структуру данных. Существующий функционал продолжает работать без изменений.

Для разработчиков:

  • Использование констант: При создании новых view-компонентов используйте константы из desktop/views/constants.py
  • Добавление новых констант: Новые текстовые строки следует добавлять в соответствующий раздел файла констант
  • Размеры окон: Размеры диалоговых окон следует выносить в константы для единообразия
  • Импорт констант: Используйте from desktop.views.constants import * в view-файлах
