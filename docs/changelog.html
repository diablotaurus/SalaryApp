ChangeLog: SalaryApp - версия v.1.2.30

Предрелизные проверки: 300 тестов; маршрутизация кнопок бота через фильтры aiogram; проверка web в браузере на dev-сервере и production; Ruff; UTF-8 без BOM; точки входа.

Подробный отчёт: docs/changelog_21.10.2026_1.2.30.html

SalaryApp v.1.2.30 current

Кратко по проделанной работе

  • UIDesktop: клик по ячейке месяца на «Главной» открывает этот месяц в окне ввода, в том числе пустой.
  • BOTКнопки в боте: текущий и прошлый месяц по МСК, сетка месяцев, «Сегодня» и «Пропустить» для дат, «Отмена»; текстовый ввод работает как раньше. Проверка доступа распространена на нажатия кнопок.
  • BOTБот понимает суммы как desktop («87 432,71» с пробелами), а «nan»/«1e5» отклоняет на своём шаге без потери введённого месяца.
  • WEBКлик по строке таблицы открывает месяц в форме; для заполненного месяца — «Сохранить изменения» с предупреждением о замене.
  • FIX«Формат экспорта по умолчанию» выбирает формат в окне экспорта; неработавший «Формат даты» убран; суммы везде в записи «87 432,71»; в web — настоящая версия, 404 для пустого месяца и корректные статусы в production.

Совместимость: схема БД не менялась, миграций и новых зависимостей нет.
