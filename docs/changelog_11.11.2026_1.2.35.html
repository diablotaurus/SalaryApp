  • ADDEDmatplotlib подгружается фоновым потоком через 0,3 с после показа окна (ChartBackendLoader). В потоке выполняется только импорт модулей, виджеты Tk там не создаются. Если открыть «Аналитику» раньше, чем загрузка закончилась, приложение дождётся её; если фоновая загрузка не удалась, импорт повторяется обычным путём.
  • CHANGEDГрафики больше не отрисовываются пустыми сразу после создания: следом они всё равно заполняются данными.
  • CHANGEDПерерисовывается только график открытой вкладки. Остальные три помечаются и дорисовываются при переходе на них, поэтому этот переход стал чуть медленнее, а смена года — заметно быстрее.
  • REFACTOREDЧетыре почти одинаковых метода создания графиков сведены к одному; описания вкладок собраны в CHART_TABS.

Запуск приложения не изменился: matplotlib по-прежнему не загружается при старте, это проверяет существующий тест точек входа.

2. Исправление: «Не удалось обновить аналитику»

БылоПричинаСтало
При открытии «Аналитики» появлялось окно «Не удалось обновить аналитику», графики и быстрые итоги оставались пустыми. Ошибка из версии 1.2.33 (прогноз года). Когда прогноз посчитать не из чего — мало месяцев с выплатами за последний год, — API отвечает «успех» без поля data, а контроллер вкладки обращался к этому полю напрямую. Отсутствие прогноза — обычная ситуация: ячейка прогноза пустая, остальная вкладка работает.
  • FIXEDReportTabController._response_data читает данные ответа безопасно.
  • FIXEDЗаглушки в тестах контроллера возвращали ответ не в том виде, что настоящий API, и ошибку не ловили. Теперь они повторяют настоящий ответ; без исправления два теста падают.
  • В production ошибка не проявлялась, потому что там прогноз есть; она проявилась бы при тех же условиях, что и на тестовой базе.
